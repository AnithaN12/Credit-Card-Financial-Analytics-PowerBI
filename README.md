# Credit-Card-Financial-Analytics-PowerBI

Developed an interactive Power BI dashboard to analyze credit card customer behavior and transaction performance. The project provides insights into revenue, transaction volume, customer demographics, card categories, and spending patterns.

# Key Performance Indicators (KPIs)

* Total Revenue: ₹55.3 Million
* Total Interest Earned: ₹7.84 Million
* Total Income: ₹575.9 Million
* Total Transaction Amount: ₹44.52 Million
* Total Transactions: 656K
* Customer Satisfaction Score (CSS): 3.19
  
# Project Process

* Data Collection: Imported credit card customer and transaction datasets.
* Data Cleaning: Prepared and transformed data for accurate analysis.
* Data Modeling: Established relationships and created calculated measures using DAX.
* KPI Development: Created key metrics to monitor revenue, interest, income, and transaction performance.
* Data Visualization: Built interactive charts, tables, and KPI cards.
* Dashboard Development: Designed two dashboards – Credit Card Customer Report and Credit Card Transaction Report.
* Interactive Analysis: Added quarterly, weekly, card category, gender, and other filters.
  
# Key Project Insights

* Blue card category generated approximately ₹46.1M in revenue.
* Q3 recorded the highest quarterly revenue at approximately ₹14.2M.
* Swipe transactions contributed approximately ₹35M in revenue.
* Businessmen contributed approximately ₹17M in revenue.
* Graduate customers generated approximately ₹22M in revenue.
* Bills were the highest revenue-generating expenditure category at approximately ₹14M.
* Male customers contributed ₹30M, while female customers contributed ₹25M.

# Tools & Technologies

* Microsoft Power BI
